正在连接天枢…

导入或扫描项目索引

方式一（推荐）：直接在天枢对话里说「帮我扫描本机全部 Agent 项目」，确认授权后插件会自动扫描并实时刷新本面板。
方式二（可选）：如果装了桌面端 Folder Index，可以在它的「更多操作 → 导出到天枢」复制 JSON 粘贴到下方；之后扫描时告诉天枢索引目录在哪（例如「索引目录在 D:\索引」），插件会记住它，并保留其中的抽屉分类。

添一个虚拟抽屉

虚拟抽屉保存在天枢插件自己的数据目录中，不会改动你的本机磁盘目录，重新扫描时会自动保留归类。
